# Учебный интернет-магазин: контрольная работа №3

**Дисциплина:** Фронтенд и бэкенд разработка  
**Тема:** Адаптивная вёрстка и доступность многостраничного HTML/CSS-сайта  
**Автор:** Горин Геннадий Евгеньевич, ЭФБО-06-25.

## Основа и цель

КР3 сделана на базе HTML/CSS-проекта КР1: [GENAG85/kr1-html-css-shop](https://github.com/GENAG85/kr1-html-css-shop). Сохранены пять страниц, содержание магазина, изображения товаров, CSS-переменные, БЭМ-классы, семантика и базовая логика формы. 

Цель: обеспечить удобное представление на телефоне, планшете и настольном компьютере без горизонтальной прокрутки всей страницы, а также улучшить доступность интерфейса.

## Состав проекта

- `index.html` — главная страница, hero, преимущества, карточки и отзывы, модальное окно заказа;
- `catalog.html` — каталог товаров, фильтры и адаптивная Grid-сетка;
- `product.html` — страница товара, адаптивное изображение и семантическая таблица;
- `order.html` — учебная форма заявки;
- `contacts.html` — контактная информация и форма обратной связи;
- `css/style.css` — базовые стили и CSS-переменные;
- `css/responsive.css` — адаптивные правила Mobile First и медиазапросы;
- `js/main.js` — мобильная навигация, каталог, dialog и проверка учебных форм;
- `images/` — исходные и оптимизированные изображения товаров разных размеров;
- `lighthouse/` — инструкция и место для реальных Accessibility-отчётов;
- `sitemap.xml` — карта страниц проекта.

## Технические решения

### Mobile First

По умолчанию компоненты имеют одноколоночный мобильный макет. В `responsive.css` используются медиазапросы `min-width: 640px`, `768px`, `1024px`, `1200px`. Эти точки выбраны под содержимое, а не под конкретную модель устройства.

- Телефон: складное меню, один столбец товаров, формы шириной по контейнеру, характеристики в виде карточек.
- Планшет: две колонки товаров, двухколоночный блок товара.
- Desktop: каталог с боковыми фильтрами, три колонки товаров на широком экране, горизонтальное меню на ширине от 1200px.
- Используются **CSS Grid** (страницы/карточки) и **Flexbox** (кнопки/меню/метаинформация).
- Отступы и ширины ограничивают переполнение; таблица не создаёт боковой скролл всей страницы.

### Responsive images

Для трёх исходных изображений созданы настоящие оптимизированные файлы `product-N-240.webp` и `product-N-480.webp` (без увеличения исходного разрешения). `<picture>`, `<source srcset sizes>` и fallback `<img>` позволяют браузеру выбирать подходящий ресурс. Присутствуют `alt`, `width`, `height`, `loading="lazy"`, а CSS ограничивает ширину изображения.

### Доступность

- На каждой странице один `h1` и семантические области `header`, `nav`, `main`, `footer`.
- Ссылка пропуска (`skip-link`) и видимый фокус через `:focus-visible`.
- Меню открывается кнопкой с `aria-expanded` и `aria-controls`, закрывается по `Escape`.
- У полей форм есть связанные `label` и корректные типы полей, у изображений — `alt`.
- Для таблицы сохранена семантика `table`, `thead`, `tbody`, а на мобильном меняется только CSS-представление.
- Диалог открывается нативным `showModal()` с поддержкой клавиатуры; уменьшение анимации через `prefers-reduced-motion`.
- Сообщения о проверке форм используют `role="status"` / `aria-live`. Учебные формы **не отправляют** данные на сервер.

## Самостоятельные улучшения

1. Кнопка мобильной навигации с `aria-expanded`, поддержкой `Escape` и видимым состоянием фокуса.
2. Раскрываемая панель фильтров для узких экранов и работающая фильтрация по категории и диапазону цены на клиенте.
3. Реальная мобильная карточная версия таблицы характеристик, при этом HTML-таблица остаётся семантической.
4. Оптимизированные WebP-изображения в двух настоящих разрешениях и `picture` с `srcset/sizes`.
5. Форма обратной связи на странице контактов; валидируется в браузере и честно сообщает, что данные не отправлены.
6. Отдельная Mobile First-архитектура CSS с адаптацией пяти страниц.
